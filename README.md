## 🌟 Highlights & Adherence to Reference
- **Hero Banner & Typography**: Pixel-perfect reproduction of the reference screenshot (`Screenshot (1).png`), featuring:
  - Exact headline typography (*"Where Tradition Meets Timeless Beauty"*) using serif Google Fonts (`Cormorant Garamond` & `Cinzel`).
  - Subtitle: *"Bridal Jewellery Designed to Be Remembered"*.
  - Delicate outlined CTA button: *"View Collection"*.
  - High-resolution, cropped asset from the reference bridal photo.
- **Live Gold Rate Ticker & Valuation Calculator**:
  - Real-time 22KT, 24KT, 18KT gold rates per gram.
  - Interactive price estimator with conversion for grams, sovereigns (pavan), and tolas.
  - Transparent itemized calculation: Pure Gold Value + Making Charges + 3% GST.
- **Multi-Currency Converter**:
  - Real-time switching between ₹ INR, $ USD, AED د.إ, £ GBP, and € EUR.
- **Curated Collections**:
  - The Bridal Suite (Featured Reference)
  - Temple & Antique 22K Gold
  - Kundan & Syndicate Polki Sets
  - Modern Daily Gold & Lightweight Luxury
- **Interactive Product Catalog**:
  - Dynamic filtering by category (Bridal, Chokers, Bangles, Earrings, Rings, Mangalsutras).
  - Purity filter (All, 22KT 916, 18KT 750).
  - Quick View modal with itemized weight, Hallmark HUID specifications, and price breakdown.
  - Wishlist (with persistence via localStorage).
  - Shopping / Consultation Bag drawer with total gold weight summary.
- **Swarna Samriddhi Gold Chit / Savings Scheme Calculator**:
  - Interactive deposit slider with 11-month payment + 12th month complimentary bonus from the jeweller.
- **VIP Bespoke Bridal Atelier Reservation**:
  - Online appointment booking with instant Atelier Pass generation.
- **WhatsApp Concierge Integration**:
  - Direct WhatsApp chat link with auto-filled product specifications and quotes.

## 🚀 How to Run the Website

Simply double-click:
```
open-website.bat
```
Or open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Brave, Safari, Firefox).

- `index.html` - Main luxury storefront & bridal atelier interface
